# AI/ML + Azure Portfolio

Five practical Python projects for an aspiring AI/ML and data engineering developer.

## Projects

1. [TerraNautics AI](./01-terra-nautics-ai/) — real-estate price estimation and investment analytics.
2. [Azure DataOps Pipeline](./02-azure-dataops-pipeline/) — data validation and transformation pipeline with Azure architecture guidance.
3. [FraudShield](./03-fraudshield/) — transaction fraud classification and evaluation.
4. [EduPredict](./04-edupredict/) — student performance prediction using synthetic demo data.
5. [MLOps Sentinel](./05-mlops-sentinel/) — model evaluation and drift monitoring starter.

## Quick start

Each project has its own README and requirements file. Use Python 3.10+ and create a separate virtual environment per project. The examples use synthetic/demo data unless you provide a real dataset. Model metrics are not claims of production performance.

## Azure note

Azure deployment is documented as an optional extension. You need your own Azure subscription and must configure credentials locally; never commit secrets, connection strings, or API keys.

## Learning path

Start with TerraNautics, then FraudShield and EduPredict. Continue to the data pipeline and finish with MLOps Sentinel. Add screenshots, experiment results, and notes from your own work before presenting these projects to employers.
